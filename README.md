# 🛡️ Discord Moderator Bot & Web Control Panel

Полнофункциональный комплекс модерации для Discord-сервера с веб-панелью управления, общей базой данных PostgreSQL и real-time синхронизацией через `LISTEN/NOTIFY`.

---

## 🚀 Стек технологий

- **Discord-бот**: Python 3.11+, `discord.py 2.x` (slash-команды, интерактивные кнопки Views, модальные окна Modals, Select-меню).
- **Веб-панель (бэкенд)**: `FastAPI`, `Uvicorn`, Discord OAuth2 (вход через Discord, проверка прав Администратора или ролей из настроек), Session Middleware.
- **База данных**: PostgreSQL, `SQLAlchemy 2.0` (AsyncIO), драйвер `asyncpg`.
- **Миграции БД**: `Alembic` (синхронный драйвер `psycopg2`).
- **Синхронизация**: PostgreSQL `LISTEN/NOTIFY` (мгновенное применение изменений настроек и кнопок из веб-панели в боте без перезапуска).
- **Фронтенд**: HTML5, Vanilla CSS (современный dark-mode дизайн с glassmorphism и микро-анимациями, шрифт Inter), Vanilla JS, Jinja2 SSR.

## ⚙️ Настройка Discord Developer Portal

1. Перейдите в [Discord Developer Portal](https://discord.com/developers/applications) и нажмите **«New Application»**.
2. В разделе **«Bot»**:
   - Нажмите **«Add Bot»** (или сбросьте токен).
   - Скопируйте **Bot Token** в `.env` (`DISCORD_TOKEN`).
   - В блоке **«Privileged Gateway Intents»** обязательно включите:
     - ✅ **Server Members Intent** (необходим для отслеживания перезаходов, выдачи и снятия ролей).
3. В разделе **«OAuth2» ➔ «General»**:
   - Скопируйте **Client ID** в `.env` (`DISCORD_CLIENT_ID`).
   - Скопируйте **Client Secret** в `.env` (`DISCORD_CLIENT_SECRET`).
   - В блоке **«Redirects»** добавьте URL:
     ```text
     http://localhost:8000/auth/callback
     ```
     *(или ваш публичный HTTPS адрес при развёртывании)*.
4. В разделе **«OAuth2» ➔ «URL Generator»**:
   - Выберите Scopes: `bot`, `applications.commands`.
   - Bot Permissions: `Administrator` (или: *Manage Roles, Manage Channels, Move Members, View Audit Log, Moderate Members, Manage Messages*).
   - Скопируйте ссылку и добавьте бота на ваш Discord-сервер.
5. Скопируйте ID вашего Discord-сервера (гильдии) и укажите его в `GUILD_ID`.

## 🔧 Конфигурация (.env)

Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```

Заполните переменные:
```dotenv
# Discord
DISCORD_TOKEN=MTE...your_bot_token
DISCORD_CLIENT_ID=123456789012345678
DISCORD_CLIENT_SECRET=abcdef123456...
DISCORD_REDIRECT_URI=http://localhost:8000/auth/callback

# Сервер Discord
GUILD_ID=123456789012345678

# База данных PostgreSQL
DATABASE_URL=postgresql+asyncpg://postgres:password@localhost:5432/discord_bot
ALEMBIC_DATABASE_URL=postgresql://postgres:password@localhost:5432/discord_bot

# Веб-панель
SECRET_KEY=change_this_to_a_very_long_random_secret_key_32chars
WEB_HOST=0.0.0.0
WEB_PORT=8000

LOG_LEVEL=INFO
```

## 🐳 Запуск через Docker Compose (Рекомендуемый)

Самый быстрый способ развернуть базу данных, выполнить миграции, запустить бота и веб-панель в изолированных контейнерах:

```bash
# 1. Запустить все сервисы в фоновом режиме
docker compose up -d --build

# 2. Проверить статус контейнеров
docker compose ps

# 3. Просмотр логов бота
docker compose logs -f bot

# 4. Просмотр логов веб-панели
docker compose logs -f web
```

Веб-панель будет доступна по адресу: [http://localhost:8000](http://localhost:8000).

## 💻 Локальный запуск (без Docker)

### 1. Подготовка окружения
Требуется Python 3.11+ и запущенный PostgreSQL.

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация окружения (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Активация окружения (Linux / macOS)
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Применение миграций базы данных
```bash
alembic upgrade head
```

### 3. Запуск компонентов

**Запуск Discord-бота:**
```bash
python -m bot.main
```

**Запуск Веб-панели (в отдельном терминале):**
```bash
uvicorn web.app:app --host 0.0.0.0 --port 8000 --reload
```

## 🎯 Основные возможности

### 1. Интерактивная модерация (`/act @пользователь`)
- Вызов команды открывает защищённое сообщение с кнопками действий:
  - 🔨 **Бан по роли**: Снимает все роли нарушителя (сохраняя их в таблице `role_backups`), перемещает пользователя в изолированную текстовую «бан-комнату», выдаёт роль бана на указанный срок.
  - 🔇 **Мут в войсе**: Отключает возможность говорить и слышать в голосовых каналах.
  - ✏️ **Мут в тексте**: Запрещает отправку сообщений в текстовых каналах.
  - ⚠️ **Варны (1/3, 2/3)**: Накопительная система предупреждений. При достижении 3/3 варнов система **автоматически банит** пользователя на 30 дней и логирует действие.
  - 🔔 **Краткосрочные предупреждения** (на 1 ч. или 6 ч.).
- Каждое действие запрашивает через модальное окно причину и срок.
- Проверка иерархии: бот не позволит наказать пользователя с ролью выше, чем у инициатора или бота.

### 2. Система разбора жалоб (`/report` и тикеты)
- Подача жалоб через slash-команду или кнопку в публичном канале жалоб.
- Анти-спам защита (по умолчанию максимум 5 жалоб в час).
- Модератор нажимает «Принять жалобу»:
  - Создаётся приватная голосовая комната в категории жалоб.
  - Истец и нарушитель перемещаются в комнату (их исходные каналы сохраняются в БД).
  - В комнате создаётся контрольная панель с кнопками вынесения вердикта.
  - По окончании разборки участники возвращаются в исходные голосовые каналы.

### 3. Фоновый планировщик (`scheduler.py`)
- Каждые 30 секунд проверяет истёкшие сроки банов, мутов и варнов.
- При снятии бана автоматически возвращает пользователю все роли, которые были сохранены до бана.
- **Защита от обхода (Anti-Bypass)**: если забаненный пользователь выходит с сервера и возвращается, бот моментально восстанавливает роль бана и удаляет неразрешённые роли.

### 4. Веб-панель управления
- **Вход через Discord OAuth2**: авторизоваться могут только Администраторы сервера и роли, явно внесённые в список доступа (`PanelAccess`).
- **Дашборд**: оперативные счётчики активных наказаний, последних репортов и быстрый поиск по ID пользователя.
- **Настройка кнопок `/act`**: настройка лейблов, эмодзи, цветов (стилей) и привязка к ролям модераторов без правок в коде.
- **Настройки сервера**: привязка ролей верификации (допуск, недопуск, пол), каналов логов, лимитов времени мута и варнов.
- **Аудит-лог**: полная история всех действий как из Discord, так и из веб-панели.
- **LISTEN/NOTIFY**: изменения в панели мгновенно пушатся в бота без задержек и без необходимости перезапускать процесс бота!
